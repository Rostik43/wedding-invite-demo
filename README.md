# Пригласительное на свадьбу — демо

Демонстрационный сайт-приглашение. Пара вымышленная, фотографии сгенерированы,
телефон в подвале ненастоящий. Сделан как витрина услуги: показать заказчику,
что сайт-приглашение умеет то, чего не может бумажная открытка.

## Что внутри

- **Конверт на первом экране.** Сургучная печать раскалывается, клапан
  откидывается, карточка выходит. Сцена привязана к прокрутке и обратима:
  крутишь назад — конверт закрывается.
- **Дата под стираемым слоем.** Гость трёт пальцем и узнаёт день.
- **Живой обратный отсчёт** до 13 июня 2027.
- Расписание дня, карта, дресс-код с палитрой, галерея.
- **Анкета гостя:** придёт или нет, +1, аллергии, трансфер, песня в плейлист.
- **Фоновая музыка** по кнопке.

## Как открыть

Двойной клик по `index.html`. Никакой сборки, никаких зависимостей.

Локальный сервер, если нужен (некоторые браузеры строги к локальным файлам):

```bash
python3 -m http.server 8766
```

## Как выложить

Скопировать на любой хостинг: `index.html`, `styles.css`, `script.js`
и папку `assets`. Больше ничего не нужно.

## Что править под конкретную пару

| Что | Где |
|---|---|
| Имена, дата, адрес, расписание, тексты | `index.html` |
| Дата для отсчёта | `script.js`, константа `WEDDING` |
| Цвета и шрифты | `styles.css`, блок `:root` |
| Фотографии | `assets/img/` |
| Музыка | `assets/audio/music.mp3` |
| Кадры открытия конверта | `assets/seq/` |

Имена на карточке в конверте — обычный текст, а не картинка: меняются
в разметке, перерисовывать ничего не надо.

## Важное

Форма **ничего не отправляет**: это демонстрация, и она честно об этом
пишет после нажатия. Чтобы ответы реально доходили, нужен бэкенд — это
отдельная работа.

Подробности решений, замеры и порядок проверки — в [СПЕКА.md](СПЕКА.md).
